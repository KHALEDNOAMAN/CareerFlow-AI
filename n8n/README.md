# n8n Workflows

This directory contains the n8n workflows for CareerFlow AI.

## How to import
1. Open your n8n instance.
2. Go to "Workflows" -> "Add Workflow".
3. Click on the 3 dots in the top right -> "Import from File".
4. Select the JSON file you want to import.
5. Configure the credentials and webhook URLs as needed.
6. Activate the workflow.
